3. PONTOS A VALIDAR (buscar 'VALIDAR' no código)
- Links marcados como #VALIDAR-URL-... (categorias, produtos, regulamento, checklist, WhatsApp, vídeos, Instagram, escolher loja).
- Bloqueio 1: regra de desconto (teto 10% x R$ 200 a cada R$ 1.000).
- Bloqueio 2: cumulatividade BITELO10 / CIMENTO10.
- Bloqueio 5: frete grátis, entrega 24h, cobrimos o melhor preço.
- Bloqueio 6: desconto vale para todos os sellers.
- Data/hora de início e fim (contador configurado até 30/11/2026 23:59 BRT, atributo data-bf26-end).

4. TÉCNICO
- CSS isolado com prefixo .bf26- (não interfere no tema).
- JS puro (setas dos carrosséis + contador). Se o Magento remover <script>, mover para o tema ou liberar no HTML Code.
- JSON-LD FAQPage no final: se alterar uma pergunta no FAQ, alterar também no JSON-LD.
- Um único H1 (hero). Title e meta description configurar no admin da página.
- Vitrines com cards fixos; cada uma tem comentário indicando onde trocar por widget Insider/Magento.
- Fonte Geologica via Google Fonts (remover o <link> se o tema já carregar).
